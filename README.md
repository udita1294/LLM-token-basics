#  Understanding Tokens in LLMs

This learning exercise explores how Large Language Models (LLMs) consume tokens while generating responses using the **Groq API**.

The goal is to understand how prompts, response length, and generation limits affect token usage and API responses.

---

##  Learning Objective

In this lesson, I learned how to:

- Understand what tokens are
- Measure prompt and completion tokens
- Use the `max_tokens` parameter
- Interpret the `finish_reason` returned by the model
- Compare token usage for different prompts

---

## Concepts Covered

### What are Tokens?

Large Language Models do not process text as complete words or sentences.

Instead, text is divided into smaller units called **tokens**.

Example:

```
Machine Learning is amazing!
```

may become

```
["Machine", " Learning", " is", " amazing", "!"]
```

Both the input prompt and the generated response consume tokens.

---

### Prompt Tokens

Tokens used by the input message.

Example:

```python
prompt = "Hi!"
```

---

### Completion Tokens

Tokens generated by the model in its response.

---

### Total Tokens

```
Total Tokens = Prompt Tokens + Completion Tokens
```

---

### max_tokens

Limits the maximum number of tokens the model can generate.

Example:

```python
response = client.chat.completions.create(
    model=model,
    messages=messages,
    max_tokens=50
)
```

---

### finish_reason

Indicates why the model stopped generating.

Common values:

| Finish Reason | Meaning |
|--------------|---------|
| stop | The model completed the response naturally. |
| length | The response stopped because `max_tokens` was reached. |
